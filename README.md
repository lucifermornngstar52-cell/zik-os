# ZikOS

Мини-операционка для планшета ZIK W1027 (и любого Android-планшета): рабочий стол, окна, таскбар, меню Пуск — в стиле Linux/Windows.

## Что внутри
- Загрузочный экран (BIOS-стиль) → рабочий стол
- Оконный менеджер: перетаскивание за заголовок, сворачивание, разворачивание, ресайз за уголок
- Панель задач: Пуск, быстрый запуск, открытые окна, часы, смена темы
- Терминал: ls, cd, cat, mkdir, touch, rm, tree, neofetch, open и др.
- Файлы: реальный домашний каталог (/home): создание, переименование, удаление
- Код: редактор с подсветкой (HTML/JS/CSS/Python/Dart/JSON), живое превью HTML
- Конвертер: единицы, системы счисления, Base64/URL/текст, метки времени
- Настройки: обои, акцент, тема, о системе

Все файлы Терминала/Файлов/Редактора живут в общем хранилище приложения.

## Сборка APK
Push в main запускает GitHub Actions: вкладка Actions → build → Artifacts → zikos-apk.
