# ZikOS (WebView Edition)

Мини-операционка для планшета ZIK W1027: рабочий стол, окна, таскбар в стиле Windows 11, терминал, файлы, редактор кода, конвертер, настройки.

Вся система — один HTML/CSS/JS файл в нативной WebView-оболочке (без Flutter). Работает на GPU с поддержкой только OpenGL ES 2.0 — Chromium рендерит сам.

Файлы и настройки хранятся в localStorage; терминал, файлы и редактор работают с одним и тем же хранилищем /home.

Сборка: push в main → Actions → Artifacts → zikos-apk.
